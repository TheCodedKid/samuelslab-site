## Core Components

### Microcontroller
The project is considering using an ESP32. A preferred layout is available at:
[https://www.adafruit.com/product/5028](https://www.adafruit.com/product/5028)

### Amplifier
An amplifier will be necessary. The PAM amplifier is still considered a good option.

## Hardware Details

### Development Boards
*   **TinyPICO:** [https://www.tinypico.com/](https://www.tinypico.com/)
*   **TinyS2:** [https://github.com/UnexpectedMaker/tinys2](https://github.com/UnexpectedMaker/tinys2)
*   **TinyS3:** [https://www.adafruit.com/product/5398](https://www.adafruit.com/product/5398)
*   **TinyPICO GitHub:** [https://github.com/tinypico](https://github.com/tinypico)

### Audio Shield
The Audio Shield for the TinyPICO is ideal for this project:
[https://github.com/tinypico/tinypico-hardware/tree/master/Shields/Audio](https://github.com/tinypico/tinypico-hardware/tree/master/Shields/Audio)

### Antenna
The **NN02** antenna will be used, as the one on the TinyPICO is deprecated:
[https://www.digikey.com/en/products/detail/ignion/NN02-101/14544286](https://www.digikey.com/en/products/detail/ignion/NN02-101/14544286)
