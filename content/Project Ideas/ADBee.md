## Overview 

Older Apple keyboards using a non-standard plug, called ADB, or **Apple Desktop Bus**. Naturally, to use it with standard HID-USB, you need a converter.

Yeah, yeah, I hear you:

Point is, there are some issues:

1. They are out of stock
2. They are expensive
3. They DO NOT WORK
4. The support sucks
5. No software programming like VIA

All of these have various levels of issues, some not being mutually exclusive.

## Status

Now a real repo — [ADBee](https://github.com/TheCodedKid/adbee), an ESP32-based ADB → USB converter.
