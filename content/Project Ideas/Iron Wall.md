# Iron Wall: Wireless Welder Control

## Overview
This project aims to develop a wireless control system for a welder, allowing for remote adjustment of welding parameters.

## Wireless Communication Module
*   **Chipset:** RFM95W
*   **Resources:**
    *   [Adafruit RFM95W LoRa Radio Transceiver Breakout](https://www.adafruit.com/product/3072)
    *   [Adafruit Radio Bonnets](https://learn.adafruit.com/adafruit-radio-bonnets)

## Hardware Integration
A breakout board will be designed to interface with the wireless module. This board will accommodate:
*   A control knob for parameter adjustment.
*   An output connection for the welder.

## Potential Features
*   Wireless charging for the control unit.

## Technical Considerations
*   Determine if power is routed through the control unit.
*   Identify the voltage requirements for the welder machine.
*   Measure the voltage range of the potentiometer at its minimum (0) and maximum (100) settings.
