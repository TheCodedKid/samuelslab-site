I really like Windows Terminal. Not [cmd](https://en.wikipedia.org/wiki/Cmd.exe#External_links), but [Windows Terminal](https://github.com/microsoft/terminal), Microsoft’s approach to a fast, flexible terminal emulator. The program is feature packed, all of this customization being possible through either the built-in editor options, or the JSON file.

  

Notion’s AI gives some pretty good surface level reasons as to why it rocks:

Windows Terminal is a modern and powerful command-line tool for Windows operating systems. It provides a customizable and feature-rich environment for running command-line applications and shells.

There are several reasons why Windows Terminal is awesome to use:

1. **Sleek and Modern Interface:** Windows Terminal offers a clean and visually appealing interface, with support for multiple tabs and customizable themes.
2. **Multiple Shells in One Place:** With Windows Terminal, you can have multiple command-line shells, such as PowerShell, Command Prompt, and Windows Subsystem for Linux (WSL), all in one application.
3. **Customization Options:** Windows Terminal allows you to customize various aspects of the interface, including color schemes, fonts, and key bindings, to suit your preferences and workflow.
4. **Powerful Productivity Features:** Windows Terminal supports advanced features like split panes, rich Unicode and emoji support, GPU-accelerated text rendering, and more, enabling you to be more productive in your command-line tasks.

  

For me, there is a couple reasons I like using it:

- **It is build like a modern emulator**
    
    Most emulators these days have their gimmicks/feature sets, and this one is now except. With Linux distros like Arch, NixOS, or similar, customizing your emulator is apart of the process. This allows the user to make it to how they want, down to the small details. Still, if you are using Windows for work, this can be a very nice tool to bring you a bit closer to home.
    
- **It’s fast**
    
    No, actually, it is. Windows program can be kinda iffy in terms of speed and resource usage, but this one is crispy. Paired with wsl, this can be quite the powerful little environment for any kind of developer.
    
- **Well-integrated into Window’s OS**
    
    I would hope so, since Windows developed it rofl.
