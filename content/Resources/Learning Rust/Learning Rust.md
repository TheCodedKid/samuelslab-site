stuff i'm collecting while learning rust, good links and resources

**start here** — [The Rust Programming Language (Official Book)](https://doc.rust-lang.org/book/) — the main book, free online, just read this first

also the older hosted versions if you prefer:
- [First Edition](https://web.mit.edu/rust-lang_v1.25/arch/amd64_ubuntu1404/share/doc/rust/html/book/first-edition/README.html)
- [Second Edition](https://web.mit.edu/rust-lang_v1.25/arch/amd64_ubuntu1404/share/doc/rust/html/book/second-edition/index.html)

[Rust by Example](https://doc.rust-lang.org/rust-by-example/) — like the book but everything is shown through code examples, nice to have open alongside

[Steve Donovan's Gentle Introduction To Rust](https://stevedonovan.github.io/rust-gentle-intro/) — softer on-ramp if the book feels like a lot

[Google Comprehensive Rust](https://google.github.io/comprehensive-rust/#welcome-to-comprehensive-rust-) — google's internal rust course, surprisingly good

[The Rustonomicon](https://doc.rust-lang.org/nomicon/) — unsafe rust stuff, not for beginners but saving it for later

**actually do these, don't just read**

[Rustlings](https://github.com/rust-lang/rustlings) — little exercises where you fix broken code, genuinely the best way to get reps in early

[Exercism Rust Track](https://exercism.org/tracks/rust) — more exercises, has mentorship if you want feedback

[Rust Playground](https://play.rust-lang.org/) — run rust in the browser, good for quick testing

**my own practice tool**

i built a little claude skill for drilling rust. the idea is simple: claude writes me a small practice problem to work through, then i can have it grill me on the code i wrote. that second part is the whole point for me — getting questioned on my own code is how i actually learn what i'm writing instead of just getting it to compile.

how i use it:
- ask claude for a rust practice problem (a quick one-file warm-up, or a bigger multi-file one to drill a specific topic)
- solve it myself
- then say "grill me on this code" and answer the questions it asks about how it works and why i made the choices i did

writing the code gets you reps, but explaining it back is what makes it stick.
